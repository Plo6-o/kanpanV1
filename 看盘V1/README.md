# 交易看板 · BOE·A500（公开版）

盘中盯盘 + 收盘复盘的一页式工具。

| 文件 | 作用 |
|---|---|
| `index.html` | **交易看板（网址根目录，手机打开就是这个）** |
| `dashboard.html` | 同一个看板（旧链接兼容） |
| `manifest.webmanifest` / `sw.js` | PWA：可「添加到主屏幕」、离线可开 |
| `icon-*.png` | 应用图标 |
| `.nojekyll` | 阻止 GitHub Pages 的 Jekyll 处理（静态站必须） |
| `可选-Actions工作流/` | 想用 Actions 部署时才需要；默认用 Settings→Pages 就不需要 |

## 隐私
- **持仓、成本、死线、待办、条件单全部只存在使用者自己浏览器的 localStorage**，不上传服务器。
- 公开的是**方法论与行情**（谁都能看、都能用）。
- 别人打开这个页面看到的是**空白模板**，需要自己填一次。

## 数据
- 行情来自腾讯行情接口 `https://qt.gtimg.cn`（实时快照，非 Level-2）。收盘后返回收盘价。
- 页面里的市场分析是**静态快照**，需手动更新。
